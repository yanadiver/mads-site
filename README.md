# Сайт — как обновлять без потери новостей

Сайт лежит на Timeweb в папке `public_html` своего домена.

## Структура
- `index.html` — сам сайт (дизайн, тексты). **Правки сайта = замена только этого файла** (и при необходимости новых картинок в `img/`).
- `img/` — картинки сайта.
- `admin/` — админка новостей: `/admin` на сайте. Пароль задаётся при первом входе и хранится на сервере в `admin/.pass.php` (в репозиторий не попадает).
- `news/news.json` и `news/photos/` — новости, добавленные через админку. **Живут только на сервере. Никогда не перезаливать и не удалять эти папки** при обновлении сайта.

## Обновление сайта
1. Правки вносятся в `index.html` в этом репозитории.
2. На Timeweb в файловом менеджере заменить только `index.html` (и добавить новые файлы в `img/`, если появились).
3. Папки `news/` и `admin/` не трогать.
